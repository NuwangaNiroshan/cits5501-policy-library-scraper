# Collaboration & Workflow Plan

## Communication
We will use Microsoft Teams for group communication.

## Meetings
We will meet once a week and when needed.

## Task Management
We will use GitHub Projects to assign and track tasks.

## Version Control
We will use GitHub with separate branches for each feature or task.

## Code Review
Changes will be submitted using pull requests and reviewed by another team member before merging.

## Resource Risks
If a member is unavailable, their important tasks will be reassigned to another team member.
